## 1. 项目概述

- **HFADM** = 无人机硬件装配数据管理系统（个人学习项目，非商业）。
- 用途：以「机型 → 部件 → 零件」产品结构树组织装配数据，零件可挂多版 PDF 图纸；支持**物理删除（无回收站、不可恢复）**、多项目共存、会话恢复、备份、**局域网远程访问（v2：配对口令 + AES-128-GCM 加密）**。
- 形态：Windows 桌面应用（Qt Widgets），一项目 = 一个 `hfadm.db` + `files/` 目录（PDF 平铺）。
- 设计理念：DB 管关系、文件管文件；**删除即物理删除**（node/drawing 表 `deleted` 字段保留但恒 0，兼容旧软删残留，不再置 1）；界面像资源管理器（目录树 + 详情表 + 多标签）。

## 2. 技术栈与构建

## 3. 分层架构（UI → Service → Model → Database）

```
MainWindow(ui/* 组件)
   ├─ Service: ProjectService(拥有唯一 DatabaseManager) · NodeService · DrawingService
   │              · RemoteServer(开放方，监听312) / RemoteClient(连接方，同步API)
   │                   ├─ 加密层: service/crypto(AES-128-GCM/BCrypt) + clientcredentialstore(客户端凭证)
   │                   └─ 远程读写复用 NodeService/DrawingService，走 JSON 行协议(v2 加密帧)
   └─ Database: DatabaseManager(统一 SQL) + DrawingRepository(drawing 专属 SQL)
        └─ SQLite: <project>/hfadm.db (WAL, foreign_keys=ON) + files/  + remote_device 表(机型库内)
   └─ Model: 纯数据结构 (hfdadnode/projectinfo/part/component/drawing/deletionplan/remotedevice)
```

- 所有 SQL 经 `DatabaseManager`（drawing 下放到 `DrawingRepository`）；浏览用 `QTableView + QAbstractTableModel`（禁 `QTableWidget`）。
- **多项目共存**：TabData 记 `projectPath`；切标签 `activateProjectContext()` 重开对应项目库（同一 DatabaseManager 复用、指向当前库），即同一时刻仅一个库打开。标签顶色带 6 色板区分归属。
- **远程上下文切换**：`RemoteServer::withProjectContext()` 处理每请求前 `openProject(绑定项目)` 切上下文、完事恢复原激活项目；单线程事件循环下切换安全。**v2 起每个业务请求额外加解密（AAD 绑定帧 id）**。
- **删除链路**：确认弹窗统计（`collectDeletionPlan`）→ `deleteNodeTree` 事务内物理删记录 → `NodeService::deleteNode` 提交后清理磁盘文件；UI 经 `ui/deleteprogressdialog` 逐项汇报。

## 5. 数据库 Schema（DatabaseManager::createTables）

库文件 `<project>/hfadm.db`；图纸 `<project>/files/`；`PRAGMA foreign_keys=ON; journal_mode=WAL;`；备份前 `wal_checkpoint(TRUNCATE)`。

- **project**：`id/name/version('1.0')/create_time/update_time/last_open_time`，单条记录（`WHERE id=1`）。
- **node**（自关联结构树）：`id/parent_id(FK,根=NULL)/name/type(1机型2部件3零件)/part_no/create_time/update_time/deleted`。**`deleted` 字段保留（DEFAULT 0，恒 0，不再置 1；兼容旧软删残留，查询仍过滤 deleted=0）**。索引：`idx_node_parent`、`idx_node_name`、部件段全机型唯一部分索引 `idx_node_part_no_component ON node(part_no) WHERE type=2 AND part_no IS NOT NULL`、零件段同父唯一 `idx_node_part_no_part ON node(parent_id,part_no) WHERE type=3`。
- **part**（零件属性）：`id/node_id(FK)/material/quantity(默认1)`。
- **component**（部件属性）：`id/node_id(FK)/quantity(默认1)`。
- **drawing**（图纸版本）：`id/part_id(FK)/file_name(如 AHZ700.3010.10A_球头.pdf)/file_path/files下相对/version(字母A…)/is_current/create_time/deleted`（deleted 同 node 保留恒 0）。索引 `idx_drawing_part`。
- **operation_log**（审计）：`id/operation/target_id/target_type(节点用NodeType值,图纸用10)/create_time`，写失败不影响主流程。
- **remote_device**（远程已授权设备，v2 新增，建在机型项目库内，CREATE IF NOT EXISTS 自动迁移旧库）：`uuid(PK)/device_name/aes_key(Base64)/permission(0只读1读写2管理)/created_at/last_seen`。首次配对成功后写入；二次连接按 uuid 查密钥与权限做挑战-响应认证。
- 关系链：`node(机型)→node(部件)→node(零件)→part/component→drawing`。**删除**：`collectDeletionPlan`（后序收集子树，叶子优先；子节点查询**不过滤 deleted** 以含旧软删残留，保证删除彻底）→ `deleteNodeTree`（事务内逐节点删 drawing→part→component→node，每删一节点回调 onNodeDeleted）。

- **CMakeLists.txt**：HFADM 目标含 23 组 ui + 8 组 service（含 v2 新增 crypto/clientcredentialstore/pairingdialog/devicemanagerdialog）；资源双前缀（welcome_assets / toolbar_icons）；exe 图标链路（icon.rc.in→configure_file→`$<$<BOOL:${WIN32}>:...>`）；`install` + `qt_generate_deploy_app_script`。疏漏：`model/component.h`、`model/deletionplan.h` 未列入主目标源清单（均 header-only 无碍）。
- **main.cpp**：建 QApplication、`setWindowIcon(:/assets/Icons/icon.svg)`、按 locale 加载 `:/i18n/HFADM_<locale>`、显示 MainWindow。
- **mainwindow.h/.cpp**：主窗口 Facade。成员：3 Service + RemoteServer* + 剪贴板来源 `RemoteClient* m_clipboardClient` + 状态栏远程标签 `m_remoteStatusLabel`。菜单：文件/编辑/**网络**/帮助；网络菜单=「开放远程访问」「关闭所有连接」「**已授权设备管理(&M)**」（开放/关闭互斥置灰；设备管理在开放状态下可用，弹 DeviceManagerDialog）。关键方法：`initServices`、`createMenus`（代码建菜单栏，不挂 QMainWindow 顶部）、`loadCurrentDirectory`（远程分支走 RemoteClient）、`updateActionState`（含远程 tab 判断：远程目录/远程PDF 标签均 `isRemoteTab()`，网络 action 全灰）、`isRemoteTab()/currentRemoteClient()`、`onOpenRemoteAccess/onCloseRemoteAccess/onConnectRemote`、`updateRemoteStatusBar`（常驻「IP:312 · N连接」）。**配对解析器**：`m_remoteServer->setPairingResolver(λ)` 在构造时设为弹窗（`showPairingDialog(this, req)`）；测试场景可替换为自动批准。**删除流程 `deleteSelectedNode`**：①`collectDeletionPlan` 汇总统计（多选合并去重）②确认弹窗「将删除其下全部 N 个节点、M 张图纸，此操作不可恢复！」③模态 `DeleteProgressDialog`（setTotal → show + processEvents 驱动 → 逐节点/逐文件 advance+addLog → 完成或失败后 exec() 等用户点关闭）。远程操作槽在重命名/删除/属性/剪贴板/图纸各槽首部分支 `isRemoteTab()` → 调 remoteoperations。剪贴板跨域：`m_clipboardClient` 记来源（本地=nullptr），粘贴时 `m_clipboardClient != 目标 remoteClient` 拒绝。生命周期：关闭被开放机型标签 → 自动 stop；远程连接断线 → 关闭该连接全部标签 + deleteLater；saveSession 跳过远程标签。**无回收站菜单/操作**。
- **mainwindow.ui**：centralwidget 垂直布局：①BrowserTabWidget ②toolbarWidget(QMenuBar+分隔线+5 QToolButton) ③searchWidget ④detailView(QTableView)。

- **projectinfo.h / part.h / component.h / drawing.h**：对应各表结构；drawing 含 `partNodeId`，文件名 `{完整图号}{字母}_{零件名}.pdf`。

### database/
- **databasemanager.h/.cpp**（约 1100 行，略超上限）：SQL 统一入口。`openDatabase`(连接名 HFADM_CONNECTION/QSQLITE)→`applyPragmaSettings`(FK+WAL)、`initializeDatabase→createTables`、事务 `begin/commit/rollback`、`checkpointWal(TRUNCATE)`。project 3 方法；node：`insertNode`(根存NULL)/`queryChildren`(根 `parent_id IS NULL` ORDER BY type,name)/`getNode`/`updateNodeName`/`updateNodePartNo`/`updateNodeParent`/`isPartNoTaken`/`searchNodesRecursive`/`searchDrawingsRecursive`/`toLikePattern`(转义)。**删除（物理删除，无回收站）**：`collectDeletionPlan`（后序收集子树+直接挂载图纸，静态辅助 `collectDeletionRecursive` 子节点查询不过滤 deleted 以含旧软删残留）+ `deleteNodeTree`（事务内逐节点 DELETE drawing(part_id IN)→part→component→node，每删一节点回调 onNodeDeleted；filePathsToRemove 输出去重后的磁盘文件相对路径）。part/component 各 4 方法。**已移除回收站四方法（softDelete/permanentDelete/恢复等）**。
- **drawingrepository.h/.cpp**：`insertDrawing`(事务：旧版 is_current=0→新=1)、`queryDrawingsByPartNode`(JOIN part, deleted=0, ORDER BY create_time DESC)、`queryDrawingById`、`setCurrentDrawing`、`getNextVersionLetter`(含已删最大字母 ASCII+1)、`permanentDeleteDrawing`、`updateDrawingVersion`(删后重排)。**已移除 softDelete/restore（回收站版本控制）**。

### service/
- **projectservice.h/.cpp**：项目管理，拥有唯一 DatabaseManager。`createProject`(建目录/拒重复/files/→开库初始化→insertProject→建机型根)、`openProject`(校验+更新 last_open_time)、`isProjectValid`(需 db+files 同存)、`backupProject`(checkpoint→复制带时间戳目录)。
- **nodeservice.h/.cpp**：节点业务与图号体系。`loadDirectory`、`createComponent`(段0–9999纯数字全机型唯一)、`createPart`(父必须部件)、`renameNode/updateNodePartNo`(机型不可改)、**`collectDeletionPlan`（收集后填充完整图号）`deleteNode`（物理删除：`deleteNodeTree` 事务删记录 → 提交后按 `m_projectPath` 解析相对路径 `QFile::remove` 清理磁盘文件，文件删除失败不影响数据一致性；回调 onNodeDeleted/onFileDeleted 供进度弹窗）**、`searchRecursive`(图纸搜索不匹配节点下图纸，drawings 恒空按需求)、`getNodePath`、`moveNode`(防环+零件只进部件)、`copyNode`(事务深拷，图纸不复制)+`findFreePartNo`。图号：`computeFullPartNo` 动态拼接——机型=名称；部件=机型名.段；零件=父完整图号.段；**子部件不继承父段**；机型改名自动刷新。
- **drawingservice.h/.cpp**：图纸导入/版本/命名。`importPdf`(仅PDF；getNextVersionLetter；`{完整图号}{字母}_{零件名}.pdf`；复制 files/；失败回滚删文件)、**`removeDrawing(drawingId, mode)` 物理删除（无回收站；`DrawingRemovalMode{KeepVersions,Renumber}`——KeepVersions 仅删、版本字母空缺保留，Renumber 前移并重命名磁盘文件；删当前且有剩余→最新设当前）**、`setCurrentDrawing`、`static resolveDrawingPath`、`buildRenamedDrawingInfo`(取第一个 `_` 前字母段)。**已移除回收站三方法**。
- **remoteprotocol.h/.cpp**：远程协议 **v2**（2026-08-05 重构，v1 明文废弃）。**帧格式：单行 JSON + '\n'**。
  - **控制帧（明文，仅握手）**：请求 `{"type":"request","cmd":"connect|auth|authResp","id":N,"body":{...}}` / 响应 `{"type":"response","id":N,"success":bool,"body":{...}}`。命令常量 `kCmdConnect/kCmdAuth/kCmdAuthResp`。
  - **业务帧（加密）**：请求 `{"type":"request","cmd":"<业务>","id":N,"body":{nonce,ciphertext,tag}}`（body 解密得业务参数）；响应 `{"type":"response","id":N,"body":{nonce,ciphertext,tag}}`（解密得 `{success,data,message}`）。cmd 在 envelope 明文，success/data/message 在密文内。**防重放：id 严格递增，AAD 绑定 id**（`encryptBody/decryptBody(key,id,payload)`）。
  - 常量：`kPort=312`、`kProtocolVersion=2`、`kRequestTimeoutMs=5000`、`kHeartbeatIntervalMs=15000`、`kSilenceTimeoutMs=60000`。
  - 权限：`enum class Permission{ReadOnly=0,ReadWrite=1,Admin=2}` + `permissionToString/FromString`；`isWriteCommand(cmd)` 供只读拦截。
  - 配对结构：`PairingRequest{uuid,deviceName,pin,peerAddress}` / `PairingResult{accepted,permission}`。
  - 22 种业务命令常量（hello/listDir/search/getNode/getPath/createComponent/createPart/renameNode/updatePartNo/updatePartAttributes/updateComponentQuantity/deleteNode/moveNode/copyNode/isPartNoOccupied/isValidPartNoFormat/computeFullPartNo/loadPart/loadComponent/importPdf/setCurrentDrawing/deleteDrawing/getDrawingFile/heartbeat）。**deleteNode/deleteDrawing 均为物理删除（不可恢复）**。序列化：node/drawing/part/component/directoryItem/时间(ISODate)。所有读写由服务端（开放方）执行，客户端只收发。
- **crypto.h/.cpp**（v2 新增）：AES-128-GCM 加解密（Windows BCrypt/CNG，无第三方依赖）。`generateKey()`(16字节)/`generateNonce()`(12字节)/`generatePin()`(4位数字口令)；`encrypt(key,nonce,plaintext,aad,ciphertext,tag)`/`decrypt(...)`（tag 校验失败返回 false）。CMake 链接 `bcrypt`；非 Windows 为兜底空实现。
- **clientcredentialstore.h/.cpp**（v2 新增）：客户端按服务端地址持久化配对凭证 `{uuid,aesKey,deviceName}` 到 QSettings（组织 HFADM、应用 RemoteClient，键 `remote/credentials/<host>`）；`load/save/clear`。认证失败/被撤销授权时清除回退配对。
- **remoteserver.h/.cpp**：服务端。`start(projectPath,projectName)` 绑定机型 + 查机型根 id 存 `m_boundRootNodeId`（握手成功响应返回给客户端）；`QTcpServer` 监听 `AnyIPv4:312`，失败报错；`stop()` 关监听+断开全部连接。**连接流程（状态机：握手→加密）**：首次 `connect`（配对）经 `setPairingResolver(std::function)` 回调（MainWindow 设为弹窗、测试自动批准）→ 存 remote_device 表；二次 `auth{uuid}` → 服务端查设备发挑战 nonce → `authResp`（客户端用密钥加密 nonce 回）→ 验证通过建会话；认证失败清凭证回退配对。**业务帧加解密分发**（AAD=id）、只读权限拦截写操作（isWriteCommand）、id 递增防重放；`withProjectContext` 模板内切绑定项目→执行→恢复。设备管理：`listAuthorizedDevices/deleteAuthorizedDevice/updateDevicePermission/renameAuthorizedDevice`（绑定项目上下文操作 remote_device 表）。内部类 `RemoteConnection`：收帧解析、静默 5s 检查/60s 判定断线。`static localAddresses()` 仅枚举 `192.168.0.0/16` 私有段 IPv4。信号：`stateChanged/connectionCountChanged/clientConnected/clientDisconnected/deviceListChanged`。importPdf 落临时目录后走 DrawingService；getDrawingFile 读文件 base64 回传。删除请求 = 服务端物理执行。
- **remoteclient.h/.cpp**：客户端。`connectTo(address)` TCP+握手（5s 超时）——**有凭证走 auth（doAuth：挑战-响应），无凭证/认证失败回退配对（doPair：生成 uuid/pin/key 发 connect）**，成功保存凭证并建加密会话；`disconnectFrom()`（`m_disconnecting` 抑制主动断开提示）。同步 API 全部走 `sendRequest`（**加密业务帧**，QEventLoop+5s 超时）；控制帧走 `sendControlRequest`（明文）；心跳 15s 定时器（fire-and-forget 不等待响应）；静默 5s 检查/60s 判定 → `connectionLost`；`fetchDrawingFile` 落 `QTemporaryDir` 临时文件返回路径；`rootNodeId()` 供远程标签初始浏览根；`pairingStarted(pin,deviceName)` 信号供 UI 提示用户注意服务端口令。

### ui/（23 对）

## 7. 关键业务规则

- **图号体系**：机型=名称；部件=机型名`.`段(0–9999、全机型唯一)；零件=父完整图号`.`段(同父唯一)。子部件不继承父段；机型改名后动态刷新。
- **物理删除（2026-08-05 改造，回收站移除）**：node/drawing 表 `deleted` 字段**保留但恒 0**（不再软删置 1，兼容旧软删残留，查询过滤 deleted=0）；删除 = 节点 + 全部子级 + 零件/部件 + 图纸记录 + 磁盘文件，**不可恢复**。删除前确认弹窗带统计（节点数/图纸数，含「此操作不可恢复」提示）；删除中模态进度弹窗（进度条 + 逐项日志，关闭按钮完成/失败后才启用）。多选删除合并统计去重；机型根节点不可删除。
- **图纸版本**：一零件多版本仅一个 is_current；导入自动取下一字母；`removeDrawing(KeepVersions)` 仅删、字母空缺保留，`(Renumber)` 前移+重命名磁盘文件；删当前且有剩余→最新设当前。
- **多项目共存**：同一 DatabaseManager 复用，切标签重开指向对应库；色带区分。
- **会话持久化**：`hfadm.session` 记录标签，上限 32；远程标签跳过；启动恢复失败/空则显欢迎页。
- **备份**：`wal_checkpoint(TRUNCATE)` 后复制 db+files 到时间戳目录。
- **远程访问（v2）**：一次开放一个机型（绑当前标签页 projectPath）；**首次配对**——客户端生成 UUID+4位口令+16字节AES密钥发 connect，服务端弹窗显示口令让用户选权限（只读/可写），存 remote_device 表，配对成功即建加密会话；**二次连接**——客户端按地址从 QSettings 读凭证发 auth，服务端查设备发挑战 nonce，客户端用密钥加密回 authResp，验证通过建会话（失败清凭证回退配对）。**业务帧全程 AES-128-GCM 加密（AAD 绑定帧 id 防重放），只读权限拦截写操作**；写操作前切绑定项目上下文、完事恢复；**服务端删除节点/图纸均为物理执行**；客户端仅限 192.168.0.0/16；同步请求 5s 超时；心跳 15s/静默 60s 断线；远程标签写后不主动广播刷新（手动刷新可见）；关闭被开放机型标签自动停止开放；断线自动清理全部远程标签；剪贴板跨域（本地↔远程）互拒；远程无回收站/备份等本地功能。设备可随时在「已授权设备管理」中删除/改权限/重命名。
